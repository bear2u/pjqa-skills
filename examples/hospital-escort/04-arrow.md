# 화살표 — 부모님 병원 동행 매칭

## AS-IS (지금 흐름)
1. 자녀가 휴가를 내거나 포기 → 2. 부모님이 혼자(또는 자녀와) 병원 이동 → 3. 진료 (자녀는 모름) → 4. 부모님이 기억나는 것만 전화로 전달 → 5. 처방전·다음 예약은 종이와 기억으로 관리

## 바꾸는 화살표 (딱 1개)
3 → 4 구간, "진료실에서 오간 이야기가 자녀에게 닿는 구간" — 지금은 부모님의 기억에 의존해 빠지고 왜곡된다
근거: J의 주 바닥(진료 중 자녀가 모르는 시간)과 겹침 / Q 채택 기능(진료 결과 리포트)이 이 구간을 바꾼다

## 그대로 두는 구간
- 병원 예약 방식 — 기존 병원 예약 그대로, 대행 연동은 2차
- 이동 방식 — 동행인의 픽업 지원 수준까지만, 차량 서비스 확장은 안 함

## TO-BE (바꾼 뒤)
일정 조율 → 병원 이동 → 진료 (동행인이 양식으로 기록) → 소견·처방·다음 예약 리포트가 자녀에게 닿음 → 관리 — 달라지는 건 3→4 구간뿐
