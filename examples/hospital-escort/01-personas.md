# 페르소나 — 부모님 병원 동행 매칭

## 주인공
### 신청하는 자녀 (예약·결제하는 사람)
- 하는 일: 동행 예약 / 결제 / 진료 결과 확인 / 다음 진료 챙기기
- 대표 불편: 회사를 빠질 수 없어 직접 모시고 가지 못한다

### 동행인 (함께 가는 사람)
- 하는 일: 픽업·이동 지원 / 접수·수납 대행 / 진료 내용 기록 / 귀가 동행
- 대표 불편: 의사 말을 빠짐없이 기록해 자녀에게 전해야 하는 부담

### 부모님 (동행 받는 주인공)
- 하는 일: 진료 정보 제공 / 거동 상태 공유 / 복용약 정보 제공
- 대표 불편: 자녀에게 짐이 되는 것 같고, 낯선 사람과 가는 것도 부담
- ※ 결제하지 않지만 설계의 중심 — 진료 과목·거동 상태·복용약이 모든 흐름의 기준 데이터

## 주변 인물 (주인공 아님)
- 병원 의료진 — 진료의 주체지만 이 서비스 흐름의 설계 대상은 아님
