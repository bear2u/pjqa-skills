# 여정 — 부모님 병원 동행 매칭

## 공통 단계
1. 예약 전 2. 병원 가는 길 3. 대기·진료 중 4. 진료 끝 5. 결과 공유

## 페르소나별 곡선
### 신청하는 자녀
| 단계 | 감정 | 이유 |
| 예약 전 | 높음 | 해결책을 찾았다는 안도 |
| 병원 가는 길 | 중간 | 잘 도착했는지 모름 |
| 대기·진료 중 | 낮음(바닥) | 안에서 무슨 이야기가 오가는지 전혀 모르는 시간 |
| 진료 끝 | 중간 | 끝났다는 것만 앎 |
| 결과 공유 | 높음 | 소견을 정확히 받아야 안심 |

### 동행인
| 단계 | 감정 | 이유 |
| 예약 전 | 중간 | 예약 확정 |
| 병원 가는 길 | 중간 | 부모님 컨디션 확인 부담 |
| 대기·진료 중 | 낮음 | 의사 말을 정확히 기록·전달해야 하는 압박 |
| 진료 끝 | 중간 | 정리는 남음 |
| 결과 공유 | 높음 | 전달 완료·정산 |

### 부모님
| 단계 | 감정 | 이유 |
| 예약 전 | 낮음 | 자녀에게 미안함, 낯선 사람 부담 |
| 병원 가는 길 | 낮음→중간 | 동행인과 대화하며 익숙해짐 |
| 대기·진료 중 | 중간 | 옆에 사람이 있어 혼자일 때보다 안정 |
| 진료 끝 | 높음 | 무사히 마침 |
| 결과 공유 | 중간 | 자녀가 알게 돼 오히려 마음 편함 |

## 바닥
- 자녀: 대기·진료 중, 아무것도 모르는 시간
- 동행인: 대기·진료 중, 기록 부담 구간
- 주 바닥: **진료 중 자녀가 아무것도 모르는 시간** (자녀의 바닥과 동행인의 기록 부담이 같은 구간에서 맞물림)

## 접점
진료 직후 결과 리포트 도착 — 동행인이 정리한 소견·처방·다음 예약이 자녀에게 닿는 순간

## 진짜 문제 (한 문장)
동행 자체가 아니라, 진료실에서 오간 이야기가 자녀에게 정확히 닿지 않는 시간이 문제다.
