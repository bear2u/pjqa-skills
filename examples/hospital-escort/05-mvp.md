# MVP — 부모님 병원 동행 매칭

## 정의문
함께 가지 못한 자녀의 진료 중 모르는 시간을, 동행인이 남기는 소견 메모와 처방·다음 예약 리포트가 닿는 것으로 바꾼다.

## 포함 (첫 버전)
- 진료 결과 리포트 — 정의문의 핵심 변화 담당
- 실시간 단계 공유 — 이동·대기 구간 담당
- 예약·결제 기본형 — 동행이 성립하기 위한 최소 토대

## 제외 (2차)
- 동행인 검증 강화 — 운영 체계 필요
- 병원 예약 대행 연동 — 병원별 연동 부담
- 진료 녹음·전사 — 동의 절차 설계 선행
- 약 배달 연계·정기 구독 — 지금 문제와 연결 약함

## 성공 신호
결과 리포트를 받은 자녀가 다음 진료에도 같은 동행인을 재예약하는 행동이 반복되는가

## 근거 추적
- 페르소나: 신청하는 자녀 (01) / 바닥: 진료 중 모르는 시간 (02) / 채택: 진료 결과 리포트 (03) / 화살표: 진료→전달 구간 (04)

## 추천 MVP 기획
### 플랫폼
- 형태: 자녀용 모바일 앱 + 부모님 접점은 문자·알림톡 병행 — 근거: 예약과 확인은 자녀가 앱으로 하지만, 부모님께 앱 설치를 요구하면 시작부터 막힌다

### 만들 순서
1. 진료 결과 리포트 루프 (바꾼 화살표 구간) — 동행인 양식 입력(소견·처방·다음 예약) → 자녀 공유 / 완료 판정: 진료 종료 후 리포트가 자녀에게 도착한다
2. 실시간 단계 공유 — 출발·도착·진료 시작·종료 알림 / 완료 판정: 단계가 바뀔 때마다 자녀에게 알림이 간다
3. 예약·결제 기본형 — 동행 예약·결제 / 완료 판정: 예약 1건이 결제까지 끝난다

### 핵심 화면 기획
- 결과 리포트 (자녀) — 목적: 진료 결과를 한 번에 파악한다 / 구성: 의사 소견, 처방, 다음 예약, 동행인 메모 / 동작: 도착 푸시를 누르면 리포트 상세가 열린다
- 단계 공유 타임라인 (자녀) — 목적: 기다리는 동안 지금 어디까지 갔는지 안다 / 구성: 출발·도착·대기·진료·종료 단계 표시 / 동작: 단계가 바뀔 때마다 알림이 간다
- 리포트 입력 양식 (동행인) — 목적: 진료를 들은 사람이 빠짐없이 남긴다 / 구성: 소견·처방·다음 예약 입력 칸, 처방전 사진 첨부 / 동작: 제출하면 자녀에게 바로 공유된다
- 동행 예약 (자녀) — 목적: 예약·결제 기본형 / 구성: 날짜·병원·동행인 선택, 결제 / 동작: 확정되면 부모님께 문자로 일정이 안내된다

### 사용자 흐름
- 예약·결제 → 동행 시작 (단계 공유) → 진료 → 동행인이 리포트 입력 → 자녀가 리포트 확인 → 다음 예약으로 이어진다

### 착수 전 결정할 것
- 동행인 최소 신원 확인 절차 (본인 확인 수준)
- 진료 정보 공유에 대한 부모님 동의 방식
