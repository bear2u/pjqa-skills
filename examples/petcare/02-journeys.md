# 여정 — 반려동물 돌봄 매칭 앱

## 공통 단계
1. 맡기기 전 2. 맡기는 순간 3. 돌봄 중 4. 첫 리포트 5. 귀가

## 페르소나별 곡선
### 맡기는 주인
| 단계 | 감정 | 이유 |
| 맡기기 전 | 높음(설렘) | 여행 준비 |
| 맡기는 순간 | 중간 | 헤어지는 순간의 미안함 |
| 돌봄 중 | 낮음(바닥) | 아무 소식 없이 시간만 감 |
| 첫 리포트 | 회복 | 사진 한 장에 안심 |
| 귀가 | 높음 | 재회 |

### 돌보는 시터
| 단계 | 감정 | 이유 |
| 맡기기 전 | 중간 | 예약 확정은 기쁨 |
| 맡기는 순간 | 중간 | 인수인계 부담 |
| 돌봄 중 | 낮음 | "잘하고 있다"를 증명해야 하는 압박 |
| 첫 리포트 | 회복 | 기록을 보내는 순간 부담이 풀림 |
| 귀가 | 높음 | 정산·좋은 리뷰 |

### 반려동물
| 단계 | 감정 | 이유 |
| 맡기기 전 | 중간 | 평소 루틴 |
| 맡기는 순간 | 낮음 | 주인과 분리 |
| 돌봄 중 | 낮음→회복 | 낯선 환경 긴장, 루틴이 맞으면 안정 |
| 첫 리포트 | 중간 | (리포트 자체보다 돌봄의 질에 반응) |
| 귀가 | 높음 | 주인 재회 |

## 바닥
- 주인: 돌봄 중, 소식이 없는 시간 전체
- 시터: 돌봄 중, 증명 부담 구간
- 주 바닥: **돌봄 중 소식 없는 시간** (주인의 바닥과 시터의 부담이 같은 구간에서 맞물림)

## 접점
첫 돌봄 리포트 도착 — 시터가 기록을 보내는 행동이 주인의 감정을 바닥에서 회복으로 바꾸는 순간

## 진짜 문제 (한 문장)
돌봄이 잘 되고 있어도, 확인 방법이 없는 시간이 문제다.
