# MVP — 반려동물 돌봄 매칭 앱

## 정의문
맡긴 주인의 모르는 시간을, 시터가 남기는 사진 세 장과 산책 경로가 실시간으로 닿는 리포트로 바꾼다.

## 포함 (첫 버전)
- 실시간 돌봄 리포트 — 정의문의 핵심 변화 담당
- 원터치 재예약 — 안심 경험의 반복 담당
- 예약·결제 기본형 — 리포트가 성립하기 위한 최소 토대

## 제외 (2차)
- 시터 검증 강화 — 운영 체계 필요
- 보험 연계 — 제휴 선행 필요
- 화상 통화·용품 쇼핑·정기 구독 — 지금 문제와 연결 약함

## 성공 신호
첫 돌봄 리포트를 받은 주인이 다음 여행에서 같은 시터를 재예약하는 행동이 반복되는가

## 근거 추적
- 페르소나: 맡기는 주인 (01) / 바닥: 돌봄 중 무소식 시간 (02) / 채택: 실시간 돌봄 리포트 (03) / 화살표: 돌봄→보고 구간 (04)

## 추천 MVP 기획
### 플랫폼
- 형태: 모바일 앱 — 근거: 시터는 현장에서 사진과 산책 경로를 남기고 주인은 푸시로 즉시 확인한다. 양쪽 접점이 모두 이동 중이라 앱이 기본이다

### 만들 순서
1. 실시간 돌봄 리포트 루프 (바꾼 화살표 구간) — 시터 기록 입력(사진·체크리스트·산책 경로) → 주인 화면 실시간 표시 / 완료 판정: 시터가 남긴 사진이 주인 화면에 바로 뜬다
2. 예약·결제 기본형 — 시터 목록·상세·예약·결제 / 완료 판정: 예약 1건이 결제까지 끝난다
3. 원터치 재예약 — 지난 시터 다시 예약 / 완료 판정: 이전 예약에서 두 번의 입력으로 재예약이 끝난다

### 핵심 화면 기획
- 돌봄 중 리포트 (주인) — 목적: 맡긴 동안 실시간으로 확인한다 / 구성: 시간순 사진, 체크리스트 상태, 산책 경로 지도 / 동작: 새 기록이 오면 푸시가 가고, 누르면 그 시각의 기록으로 이동한다
- 돌봄 기록 입력 (시터) — 목적: 최소 입력으로 기록을 남긴다 / 구성: 사진 촬영, 체크리스트 토글, 산책 시작·종료 버튼 / 동작: 산책 경로는 GPS가 자동 기록하고, 전송 즉시 주인 화면에 반영된다
- 시터 찾기·예약 (주인) — 목적: 예약·결제 기본형 / 구성: 시터 목록·프로필·가능 시간, 예약 요청, 결제 / 동작: 예약이 확정되면 양쪽에 돌봄 일정이 생긴다
- 재예약 (주인) — 목적: 지난 시터를 한 번에 다시 예약한다 / 구성: 지난 돌봄 이력, 같은 조건으로 예약 버튼 / 동작: 날짜만 골라서 요청한다

### 사용자 흐름
- 시터 찾기 → 예약·결제 → 돌봄 시작 (시터가 기록) → 주인이 리포트로 확인 → 돌봄 종료 → 같은 시터 재예약

### 착수 전 결정할 것
- 산책 경로 기록 방식 (상시 GPS / 시작·종료 구간 기록)
- 초기 시터 모집 방법
