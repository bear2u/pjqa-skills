# 화살표 — 반려동물 돌봄 매칭 앱

## AS-IS (지금 흐름)
1. 지인에게 부탁 → 2. 카톡으로 일정 조율 → 3. 돌봄 진행 (소식 없음) → 4. 끝나고 나서야 카톡 보고 → 5. 계좌이체

## 바꾸는 화살표 (딱 1개)
3 → 4 구간, "돌봄 중의 기록이 주인에게 닿는 구간" — 지금은 돌봄이 끝나야만 소식이 닿는다
근거: J의 주 바닥(돌봄 중 무소식 시간)과 정확히 겹침 / Q 채택 기능(실시간 돌봄 리포트)이 이 구간을 바꾼다

## 그대로 두는 구간
- 부탁·조율 방식 — 첫 버전은 기본형 예약으로 대체하되 흐름 자체는 유지
- 정산 — 계좌이체 수준의 기본 정산 유지 (자동 정산 고도화는 2차)

## TO-BE (바꾼 뒤)
지인 부탁 → 일정 조율 → 돌봄 진행 (기록이 실시간으로 닿음) → 보고 → 정산 — 달라지는 건 3→4 구간뿐
