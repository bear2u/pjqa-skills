# 페르소나 — 반려동물 돌봄 매칭 앱

## 주인공
### 맡기는 주인 (돌봄을 맡기는 사람)
- 하는 일: 시터 탐색 / 예약·결제 / 돌봄 리포트 확인 / 리뷰
- 대표 불편: 맡긴 뒤 잘 지내는지 알 방법이 없다

### 돌보는 시터 (돌봄을 제공하는 사람)
- 하는 일: 프로필·일정 관리 / 돌봄 기록 / 정산
- 대표 불편: 잘하고 있다는 걸 증명할 방법이 마땅치 않다

### 반려동물 (돌봄 받는 주인공)
- 하는 일: 건강 정보 제공 / 특이사항 / 복용약 관리 대상
- 대표 불편: 낯선 환경과 바뀐 루틴에서 오는 스트레스
- ※ 결제하지 않지만 설계의 중심 — 건강 프로필·특이사항·복용약이 모든 흐름의 기준 데이터

## 주변 인물 (주인공 아님)
- 동물병원 — 응급 시 연계 대상일 뿐 일상 흐름의 주체가 아님
