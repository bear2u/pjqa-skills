# AS-IS (지금 흐름, 에이전트 없이)
1. 장을 보며 대응 규칙을 머릿속으로 정한다 → 2. 알람을 맞춰 놓고 잔다 → 3. 급등락이 온다 (자고 있어 놓친다) → 4. 아침에 손실부터 확인한다 → 5. 대응은 다음 장에서 수동으로 한다

## 바꾸는 화살표 (딱 1개)
3 → 4 구간: "놓친 급등락이 아침의 손실 확인이 되는 구간"을 바꾼다. 급등락이 오면 에이전트가 정해진 규칙대로 실행하고 전 과정을 기록한다. 아침에 투자자가 맞는 것은 손실 통보가 아니라 검증할 기록이다.
- 근거: J의 주 바닥이 "맡겼지만 확인할 방법이 없는 구간"이고 Q의 채택이 실행 리플레이이기 때문이다

## 그대로 두는 구간
- 규칙을 정하는 일 (전략은 사람의 것)
- 아침에 결과를 확인하는 습관 (확인 대상만 손실 → 기록으로 바뀐다)
- 거래소 선택과 입출금

## TO-BE
급등락 → 에이전트 실행·기록 → 아침엔 손실 확인이 아니라 실행 리플레이 검증. 사람은 규칙을 정하고 결과를 검증하는 자리로 이동한다.
