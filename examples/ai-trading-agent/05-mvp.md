# MVP 정의 — AI 트레이딩 에이전트 (코인)

## 정의문
자는 투자자의 모르는 밤을, 규칙대로 실행한 전 과정이 아침에 리플레이로 검증되는 기록으로 바꾼다.

## 포함 (첫 버전)
- 실행 전 과정 리플레이 — 정의문의 "검증되는 기록" 담당
- 규칙 범위 밖 주문 차단 — 정의문의 "규칙대로"를 보장하는 장치
- 규칙 실행 기본형 — 손절·익절 조건 실행 + 거래소 1곳 연동, 정의문의 "실행" 담당

## 제외 (2차)
- 규칙 백테스트 사전 검증 — 실행 기록 검증이 먼저
- 전략 자동 생성 — 책임·검증 체계 선행 필요
- 급등락 즉시 깨우기 — 위임의 목적과 충돌
- 다중 거래소 연동 — 첫 버전은 1곳으로 검증

## 성공 신호
첫 급등락이 지난 아침, 투자자가 리플레이를 끝까지 확인한 뒤 에이전트를 끄지 않고 다음 밤에도 그대로 맡기는가.

## 근거 추적
- 페르소나: 맡기는 투자자 (01) / 바닥: 맡겼지만 확인할 방법이 없는 구간 (02) / 채택: 실행 리플레이·범위 차단 (03) / 화살표: 급등락→아침 구간 (04)

## 추천 MVP 기획
### 플랫폼
- 형태: 모바일 앱 (사용자 접점) + 서버 에이전트 (감시·실행) — 근거: 핵심 접점이 아침 푸시 알림과 즉시 정지라 앱이 맞고, 24시간 감시와 실행은 폰이 꺼져 있어도 돌아야 해서 서버가 맡는다
- 구성: 앱 — 규칙 설정·리플레이 확인 / 서버 — 시세 감시·주문 실행·전 과정 기록

### 만들 순서
1. 실행 기록 리플레이 (바꾼 화살표 구간) — 발동·주문·체결을 타임라인으로 기록하고 리플레이 화면으로 재생 / 완료 판정: 밤사이 실행 1건이 처음부터 끝까지 리플레이된다
2. 규칙 실행 기본형 + 범위 차단 — 규칙 설정 화면과 에이전트 상태 화면 포함 / 완료 판정: 정한 조건에서만 주문이 나가고 범위 밖 주문은 차단된다
3. 거래소 연동 (1곳) + 아침 요약 — 연동 화면과 홈 요약, 아침 푸시 / 완료 판정: 아침에 밤사이 요약 푸시가 도착한다

### 핵심 화면 기획
- 홈 (밤사이 요약) — 목적: 아침 10초 안에 밤사이 결과를 파악한다 / 구성: 실행 건수, 발동한 규칙, 차단된 주문 배지, 밤사이 손익 범위 / 동작: 요약 카드를 누르면 해당 리플레이로 이동하고, 발동이 없던 밤은 "발동 없음"으로 표시한다
- 실행 리플레이 — 목적: 실행 1건을 처음부터 끝까지 검증한다 / 구성: 타임라인 (발동 시각·당시 시세·주문·체결·범위 검사 결과), 발동 이유 하이라이트 / 동작: 구간 이동과 배속 재생, 이상 구간만 골라 보기
- 규칙 설정 — 목적: 손절·익절 조건과 권한 범위를 정한다 / 구성: 조건 입력 (가격·등락률), 1회 최대 금액·하루 한도, 적용 시간대 / 동작: 저장 전에 범위 검사를 미리 보여 주고, 범위를 벗어난 값은 저장 자체가 막힌다
- 에이전트 상태 — 목적: 지금 감시 중인지 알고, 즉시 멈출 수 있다 / 구성: 상태 표시 (감시 중·정지), 비상 정지 버튼, 거래소 연동 상태 / 동작: 정지를 누르면 대기 주문 취소와 감시 중단이 즉시 일어난다
- 거래소 연동 — 목적: 거래소 1곳을 안전하게 연결한다 / 구성: 거래소 선택, API 키 입력, 권한 단계 표시 (조회 → 매매) / 동작: 잔고 조회 테스트가 성공해야 매매가 활성화된다

### 사용자 흐름
- 거래소 연동 → 규칙 설정 → 감시 시작 → 밤사이 발동 시 실행·기록 → 아침 요약 푸시 → 리플레이 검증 → 규칙을 고치거나 그대로 둔다

### 착수 전 결정할 것
- 첫 연동 거래소
- 규칙 표현 범위 (가격 조건만 / 지표 조건 포함)
