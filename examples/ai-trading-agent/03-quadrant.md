| 후보 | 위치 | 근거 (어느 아픈 지점인가) |
|---|---|---|
| 실행 전 과정 리플레이 | 왼쪽 위 | "맡겼지만 확인할 방법이 없다"는 주 바닥 그 자체 |
| 규칙 범위 밖 주문 차단 | 왼쪽 위 | 검증이 되려면 애초에 범위를 벗어난 실행이 없어야 한다 |

| 급등락 즉시 깨우기 (전화) | 아래 | 깨우는 순간 위임의 목적이 무너진다 |

## 채택 (왼쪽 위, 최대 3개)
- 실행 전 과정 리플레이 — 발동 이유·주문·체결을 타임라인으로 재생해 검증 가능하게 한다
- 규칙 범위 밖 주문 차단 — 정한 범위를 벗어난 주문은 실행 자체를 거부한다

## 2차로 미룸
- 규칙 백테스트 사전 검증 — 맡기기 전 검증으로 유효하지만, 실행 기록 검증이 먼저다
- 전략 자동 생성 — 책임과 검증 체계가 선행돼야 한다
- 급등락 즉시 깨우기 — 위임의 목적과 충돌해 기본값으로는 넣지 않는다
- 수익률 대시보드 — 지금 문제와 연결이 약하다
