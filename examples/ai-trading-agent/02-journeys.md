# 공통 단계
1. 규칙을 맡기기 전 2. 맡긴 첫날 밤 3. 급등락이 온 순간 4. 아침에 결과를 볼 때 5. 다음 급등락

### 맡기는 투자자
| 단계 | 감정 | 이유 |
|---|---|---|
| 규칙을 맡기기 전 | 높음 | 드디어 밤에 잘 수 있다는 기대 |
| 맡긴 첫날 밤 | 낮음 | 맡겨 놓고도 불안해서 새벽에 깬다 |
| 급등락이 온 순간 | 중간 | 자고 있어 아무것도 모른다 |
| 아침에 결과를 볼 때 | 낮음→회복 | 결과만 보면 불안하고, 기록을 보면 안도한다 |
| 다음 급등락 | 높음 | 검증한 뒤에야 믿고 잔다 |

### 실행하는 에이전트
| 단계 | 감정 | 이유 |
|---|---|---|
| 규칙을 맡기기 전 | 중간 | 규칙을 받아 대기한다 |
| 맡긴 첫날 밤 | 중간 | 감시 중, 발동 없음 |
| 급등락이 온 순간 | 높음 | 조건이 발동해 규칙대로 실행한다 |
| 아침에 결과를 볼 때 | 낮음 | 실행은 끝났는데 주인이 봤는지 알 수 없다 |
| 다음 급등락 | 중간 | 다음 발동을 대기한다 |

### 주문을 받는 거래소
| 단계 | 감정 | 이유 |
|---|---|---|
| 규칙을 맡기기 전 | 중간 | 주문 접수가 정상이다 |
| 맡긴 첫날 밤 | 중간 | 새벽에도 정상 운영 |
| 급등락이 온 순간 | 낮음 | 트래픽이 몰려 주문이 지연·거부된다 |
| 아침에 결과를 볼 때 | 회복 | 정상화되고 체결 결과가 확정된다 |
| 다음 급등락 | 중간 | 평상시로 돌아간다 |

## 바닥 (공통 구간)
- **주 바닥**: 맡긴 첫날 밤부터 첫 급등락 다음 날 아침까지 — 맡겼지만 규칙대로 했는지 확인할 방법이 없는 구간
- 투자자: 첫날 밤, 맡겨 놓고도 불안해 깨는 시간
- 에이전트: 실행을 마친 뒤 주인이 확인했는지 알 수 없는 시간
- 거래소: 급등락 순간 주문이 지연·거부되는 시간

## 접점
아침 실행 리포트 — 에이전트가 밤사이 실행 기록을 남기는 행위가 투자자의 아침 감정을 가른다. 기록이 있으면 검증이 되고, 없으면 불안이 된다.

## 진짜 문제
급등락 대응 자체는 규칙 실행으로 해결된다. 남는 문제는 위임의 검증이다. 규칙대로 실행했는지 보여 주는 기록이 없으면, 자동 실행은 맡기는 것이 아니라 방치하는 것이다.
